Backend architecture development on Cloudflare (D1 + Workers + Workflows + R2) with Clerk authentication webhooks, OpenRouter AI pipeline integration, and Resend email delivery. Frontend integration and end-to-end integration support are included as a full project discount for this quotation.

Deliverables

A. Product Management & Design Deliverables (included in Management Fee)

  1. Product Requirements Document (PRD) — Full backend proposal with technology rationale, request lifecycle, AI methodology framework (Bloom's Taxonomy, STAR Method, O*NET, NACE, Rubric-Anchored Evaluation), and operational policies.
  2. Entity Relationship Diagram (ERD) — 12-entity canonical data model with column specifications, lifecycle policies, referential rules, interaction models, and recommended indexes.
  3. UX Flow Comparison — 17-route current (Supabase) vs. proposed (Cloudflare) user journey analysis with impact assessment per route.
  4. Backend Architecture Design — Before & After architecture mapping, service selection rationale (Clerk vs. Supabase Auth, D1 vs. PostgreSQL, Workers vs. Edge Functions, OpenRouter vs. direct API, Resend vs. stub).

B. Development Deliverables

  1. Cloudflare D1 Database — Full schema with 12 tables, migrations, indexes, and constraints.
  2. Cloudflare R2 Storage — Resume PDF storage with user-scoped access.
  3. Clerk Authentication — Frontend components, webhook user sync, JWT middleware, role-based access control.
  4. Employer & Employee Pipeline — Backend workflow coverage for employer-side hiring flows and employee-side application/progression flows created as part of this prototype delivery.
  5. AI Resume Feedback Workflow — 6-step durable Cloudflare Workflow with OpenRouter inference, output normalization, admin review lifecycle, and Resend notification.
  6. AI Interview Prep Workflow — Categorized question generation (technical, behavioral, situational) with quota enforcement and deduplication.
  7. Admin Panel Backend — Feedback review, waitlist management, CSV export, audit logging.
  8. Waitlist & Contact Workers — Public form processing with email confirmation.
  9. Resend Email System — Transactional email with SPF/DKIM/DMARC, 3 templates.
  10. Frontend API Integration — All React hooks and components rewired from Supabase client to Cloudflare Worker endpoints.
  11. End-to-End Integration Testing — Full flow verification for all 9 epics.
