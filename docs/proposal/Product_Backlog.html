Kraftworks Career Hub — Product Backlog & Project Analysis

Complete sprint backlog, epic analysis, timeline breakdown, and pricing for the Cloudflare backend migration

Version 1.0  |  March 27, 2026  |  Aligned with: ERD Model, Backend Architecture Proposal (Section 6 & 7), UX Flow Comparison  |  Engineer: Mahmud Asrul (Solo Product Engineer)

Scope. This document covers the full backend migration from Supabase to the proposed Cloudflare stack (Clerk + D1 + R2 + Workers + Workflows + OpenRouter + Resend), including all necessary frontend API integration changes and end-to-end integration testing. Every backlog item traces directly to an ERD entity, a backend architecture component, or a UX flow documented in the companion proposal files.

Story Point Convention. FE Frontend work (React component changes, API call rewiring, UI state updates). BE Backend work (Workers, D1 schema, Workflows, external service integration). INT Integration testing (end-to-end flow verification, edge case testing, deployment validation).

Total formula: Total = max(FE, BE) + Integration — because a single engineer executes FE and BE sequentially per story, so the longer track determines base effort, plus integration is always additive.

Throughput: 8 story points per day (senior engineer, 4 focused hours/day, ~30 min per SP average).
